한 줄 요약

번들 asset 2개를 받아 설정 디렉터리에 설치하고 statusLine 을 그 경로로 설정합니다

INPUT
assets/*.sh
statusline-command · statusline-tokens
→
SKILL
/claudecode:statusline-setup
install-statusline.sh
→
OUTPUT
$CFG/*.sh
+ settings.json
statusLine 블록 추가
0
exit code
2
설치된 스크립트
17162
statusline-command.sh (bytes)
5576
statusline-tokens.sh (bytes)

1. 실행한 명령

dry-run 을 먼저 돌리고 그 다음 실제 설치

범용 형식

/claudecode:statusline-setup [--dry-run]
    [--usage-id ID --usage-api URL] [--budget N]

이번 실행

CLAUDE_CONFIG_DIR="$CFG" \
  sh .../install-statusline.sh --dry-run

CLAUDE_CONFIG_DIR="$CFG" \
  sh .../install-statusline.sh

사용자의 실제 ~/.claude 를 건드리지 않도록 격리 검증용 임시 설정 디렉터리 $CFG 를 대상으로 실행했습니다. Bedrock 비용 플래그는 넘기지 않았습니다.

2. 입력

번들 asset 2개와, 앞선 cache-ttl 실행 결과가 남아 있는 settings.json

입력내용
skills/statusline-setup/assets/statusline-command.sh17162 bytes
skills/statusline-setup/assets/statusline-tokens.sh5576 bytes
$CFG/settings.jsonmodel · env (SOME_OTHER_KEY, ENABLE_PROMPT_CACHING_1H) · permissions

3. 결과

dry-run 은 아무것도 쓰지 않았고, 실제 설치는 exit 0

--dry-run 아무것도 쓰지 않음

would install $CFG/statusline-command.sh (mode 755)
would install $CFG/statusline-tokens.sh (mode 755)
would set .statusLine.command = $CFG/statusline-command.sh in $CFG/settings.json
dry run: nothing written.

install exit 0

installed $CFG/statusline-command.sh
installed $CFG/statusline-tokens.sh
statusLine.command = $CFG/statusline-command.sh
Restart Claude Code to pick it up.
결과 파일모드비고
$CFG/statusline-command.sh-rwxr-xr-x새로 설치
$CFG/statusline-tokens.sh-rwxr-xr-x형제로 나란히 설치
$CFG/settings.json-rw-------statusLine 블록 추가
키실행 후
statusLine.type"command" 추가
statusLine.command$CFG/statusline-command.sh (절대 경로) 추가
model · env · permissions전부 그대로 보존
