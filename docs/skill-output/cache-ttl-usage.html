cache-ttl 사용 결과

스킬을 실제로 한 번 실행한 기록입니다. 아래의 명령, 경로, 출력, 종료 코드는 전부 실제 실행 결과입니다.

command set-cache-ttl.sh 1hexit 0target $CFG/settings.json

1. 실행한 명령

범용 형식과 이번 실행에 쓴 실제 명령

범용 형식

/claudecode:cache-ttl [1h|5m]

이번 실행

CLAUDE_CONFIG_DIR="$CFG" \
  sh skills/cache-ttl/scripts/set-cache-ttl.sh 1h

사용자의 실제 ~/.claude 를 건드리지 않도록, 격리 검증용 임시 설정 디렉터리 $CFG 를 대상으로 실행했습니다.

2. 입력

$CFG/settings.json — model, env.SOME_OTHER_KEY, permissions 를 가진 기존 설정 파일

{
  "model": "opus",
  "env": { "SOME_OTHER_KEY": "keep-me" },
  "permissions": { "allow": ["Bash(ls:*)"] }
}

3. 결과

exit 0 — 스크립트가 출력한 그대로

cache TTL: 5m -> 1h  (env.ENABLE_PROMPT_CACHING_1H: (unset) -> 1)
file: $CFG/settings.json
Restart Claude Code to pick it up.
키실행 전실행 후
