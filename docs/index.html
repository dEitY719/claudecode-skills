claudecode skills

Claude Code 자기 자신을 설정하는 스킬 2개 — 프롬프트 캐시 TTL 과 상태줄. 둘 다 settings.json 의 키 하나씩만 건드리고 나머지는 전부 보존합니다.

dotfiles 없이 동작합니다. 필요한 셸 스크립트와 상태줄 asset 이 전부 플러그인 안에 들어 있어, dEitY719/dotfiles 를 한 번도 클론하지 않은 PC 에서도 같은 결과가 나옵니다 (#1751 NF-1). jq 는 필수이며, 없으면 sed 로 우회하지 않고 그냥 멈춥니다.

스킬 2개

cache-ttl

/claudecode:cache-ttl [1h|5m]

env.ENABLE_PROMPT_CACHING_1H 를 뒤집어 프롬프트 캐시 수명을 1시간으로 늘리거나 기본 5분으로 되돌립니다. 5m 은 키를 지우고, 그 결과 .env 가 비면 .env 까지 제거합니다.

설명서

statusline-setup

/claudecode:statusline-setup [--dry-run]

번들된 statusline-command.sh 와 statusline-tokens.sh 를 Claude 설정 디렉터리에 설치하고 .statusLine 을 그 절대 경로로 설정합니다. 기존 파일이 다르면 .bak 부터 남깁니다. bash 4.4+ 필요.

설명서

공통 안전 계약

두 스크립트는 가장자리에서 똑같이 동작하고, tests/run.sh 가 그것을 강제합니다.

jq 아니면 중단

jq 가 없으면 설치 안내를 출력하고 exit 3. sed 나 python 폴백은 없습니다 — 어중간하게 파싱한 JSON 편집은 거절보다 나쁩니다.

깨진 JSON 은 덮어쓰지 않음

jq -e . 를 통과하지 못하는 settings.json 은 .bak 으로 복사만 하고 exit 4. 아무것도 쓰지 않습니다.

손실 없는 병합

hooks · model · permissions 등 무관한 키는 전부 살아남습니다. 임시 파일에 쓴 뒤 mv 하므로 jq 실패가 원본을 자르지 못합니다.

멀티 계정

대상은 ${CLAUDE_CONFIG_DIR:-$HOME/.claude}. 호출 전에 그 변수를 지정하면 계정별로 따로 설정됩니다 (#1751 F-5).
